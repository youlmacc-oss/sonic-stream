SonicStream 설치 안내
==================

이 프로그램은 인터넷 사이트가 아니라, 내 컴퓨터에 설치해서 사용합니다.
Python이나 Node.js를 따로 설치할 필요는 없습니다.

웹에서 설치
----------
1. SonicStream 사이트에서 설치에 동의합니다.
2. 동의하고 설치하기를 누릅니다.
3. 받은 SonicStream-설치.bat 을 엽니다.
4. 설치가 끝나면 바탕화면 바로가기를 만들지 물을 수 있습니다. 프로그램은 바로 실행됩니다.
5. AI 검색을 쓰려면 OpenAI API 키를 넣습니다. 설치 창에서 넣거나, 실행 후 화면 가운데에서 넣을 수 있습니다.

파일로 설치
----------
1. SonicStream-Windows.zip 파일을 USB나 메일, 클라우드로 이 컴퓨터에 복사합니다.
2. 압축을 풉니다.
3. 설치하기.bat 을 더블클릭합니다.
4. 바탕화면 바로가기 여부를 고르면 프로그램이 바로 실행됩니다.

설치 위치는 보통 아래입니다.
  C:\Users\사용자이름\AppData\Local\SonicStream

받은 영상은 기본으로 아래 폴더에 저장됩니다.
  다운로드\SonicStream
화면에서 폴더 바꾸기를 누르면 다른 폴더로 바꿀 수 있습니다.

프로그램을 지울 때는 제거하기.bat 을 실행하세요.
받은 영상은 삭제되지 않습니다.

개발용 시작하기.bat 은 일반 사용자가 쓸 필요가 없습니다.
