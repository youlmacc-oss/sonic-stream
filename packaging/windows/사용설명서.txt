SonicStream 사용 설명서
====================

시작
----
설치가 끝나면 프로그램이 바로 실행됩니다.
이후에는 바탕화면 또는 시작 메뉴의 SonicStream을 누릅니다.
브라우저가 열리면 바로 사용할 수 있습니다.
검은 창을 계속 열어 둘 필요는 없습니다.
아이콘을 다시 누르면 이미 켜진 화면만 다시 엽니다.

AI 검색
------
화면 가운데의 OpenAI API 키에 키를 넣고 저장하고 연결을 누릅니다.
키는 이 컴퓨터에만 저장되며, 위쪽 연결 상태에서 AI 연결됨을 확인할 수 있습니다.

영상 받기
--------
1. 주소창에 있는 동영상 주소를 복사합니다.
2. SonicStream의 붙여넣기를 누릅니다.
3. 영상, 세로·쇼츠, 오디오 중에서 고릅니다.
4. 다운로드를 누릅니다.
5. 끝나면 동영상 열기 또는 저장 폴더 열기를 누릅니다.

저장 폴더
--------
화면 가운데의 폴더 바꾸기로 원하는 폴더를 고릅니다.
지금 폴더 열기를 누르면 받은 파일이 있는 곳을 볼 수 있습니다.

글자가 작을 때
------------
오른쪽 위의 더 큰 글씨를 누르세요.

컴퓨터가 켜질 때 자동 시작
----------------------
화면의 "컴퓨터가 켜지면 SonicStream도 시작"에 표시하면 됩니다.

종료
----
화면의 프로그램 종료를 누르거나, 설치 폴더의 종료하기.bat을 실행합니다.
받은 파일은 그대로 있습니다.

프로그램 삭제
----------
제거하기.bat을 실행합니다. 받은 영상은 남습니다.

알아두기
------
이 프로그램은 이 컴퓨터에서만 받습니다.
웹사이트 서버로 받는 방식은 사용하지 않습니다.
모든 영상이 항상 받아지는 것은 아닙니다.
